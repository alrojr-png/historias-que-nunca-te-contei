# Histórias que nunca te contei

Versão digital (para celular) do jogo de cartas criado por alunos da Escola do Sebrae.

- No ar para teste: https://historias-que-nunca-te-contei.vercel.app
- Site estático: `index.html` + `cartas.js` + imagens em `cartas/` e `img/`. Não precisa de build.
- As cartas são recortes dos PDFs originais de impressão, sem nenhuma alteração. `cartas.js` traz o texto de cada carta (usado só como texto alternativo).

Para rodar localmente: `python -m http.server` nesta pasta e abrir http://localhost:8000
